# M S Store - Shopify Store Website

Welcome to M S Store! This is a complete e-commerce website built with HTML, CSS, and JavaScript.

## 📋 Features

- **Home Page**: Hero section with featured products
- **Products Page**: Display of all available products
- **Shopping Cart**: Add/remove products, calculate totals
- **About Page**: Information about the store
- **Contact Page**: Contact form and business information
- **Responsive Design**: Works on all devices
- **Local Storage**: Cart data persists in browser

## 🛍️ Pages

1. **index.html** - Home page with featured products
2. **products.html** - All products catalog
3. **cart.html** - Shopping cart management
4. **about.html** - About the store
5. **contact.html** - Contact information and form

## 🎨 Styling

- **styles.css** - Complete styling for all pages
- Modern, clean design
- Fully responsive layout
- Smooth transitions and animations

## ⚙️ Functionality

- **script.js** - Shopping cart logic
- Add products to cart
- Update quantities
- Remove items
- Calculate totals with tax
- Contact form submission
- Local storage for cart persistence

## 🚀 How to Use

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Browse products and add to cart
4. View cart and proceed to checkout
5. Contact us through the contact page

## 📝 Customization

### Change Store Name
Replace "M S Store" with your store name in all HTML files and styles.css

### Add Products
Edit the product cards in `products.html` to add your own products

### Update Colors
Modify the color values in `styles.css`:
- Primary color: #3498db (blue)
- Secondary color: #27ae60 (green)
- Dark color: #2c3e50 (dark gray)

### Add Images
Replace placeholder images with your own product images:
```html
<img src="your-image-url.jpg" alt="Product Name">
```

## 📱 Responsive Breakpoints

- Tablet: 768px - 1199px
- Mobile: Below 768px
